# VeterinerUygulamasi

[![C](https://img.shields.io/badge/C-A8B9CC?style=flat-square&logo=c&logoColor=black)]()

Veteriner kliniklerinde hasta (evcil hayvan) takibi için geliştirilmiş bir konsol uygulaması.

## Proje Hakkında

Uygulama, evcil hayvanların randevu ve kontrol süreçlerini yönetmeyi amaçlar. Örnek işlevlerden bazıları:

- Randevu alma (`randevuAl`)
- Kedi yaşını "insan yaşına" çevirme hesaplaması (`kedininInsanYasiniHesapla`)
- Son kontrolden itibaren geçen süreye göre kontrol zamanının gelip gelmediğini belirleme (`kontrolZamaniGecmisMi`)

## Kullanılan Teknolojiler

- C

## Kurulum ve Çalıştırma

```bash
git clone https://github.com/mrvbyrm/VeterinerUygulamasi.git
cd "VeterinerUygulamasi/Veteriner_Uygulaması"
gcc "Veteriner_Uygulaması.c" -o veteriner
./veteriner
```

Detaylı proje raporu için `Veteriner_Uygulaması.pdf` dosyasına bakabilirsiniz.
